## CIFAR-10 Dataset Image Classification using multiple machine learning algorithms

This project implements several machine learning algorithms to classify images from the CIFAR-10 dataset. The algorithms implemented include:
- K-Nearest Neighbors (KNN)
- Support Vector Machine (SVM)
- Softmax Regression
- Two-layer Neural Network

The project is structured as follows:
- `KNN-Classifier`: Contains the implementation of the KNN algorithm.
- `SVM-Classifier`: Contains the implementation of the SVM algorithm.
- `Softmax-Regression`: Contains the implementation of the softmax regression algorithm
- `Two-layer-Neural-Network`: Contains the implementation of a two-layer neural network.
- `utils`: Contains utility functions and code for the project

The project is open source and is available on GitHub. Students and practitioners of deep learning for computer vision can use the materials in this repository to learn and practice their skills in this exciting field.
