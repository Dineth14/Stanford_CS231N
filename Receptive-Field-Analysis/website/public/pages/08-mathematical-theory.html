Section 08

Mathematical Theory

Complete derivations: SSM discretisation, CNN as finite-impulse SSM, attention as kernel regression, and the SSM transfer function in the frequency domain.

SSM Discretisation Derivation

Starting from the continuous-time ODE:

$$\dot{h}(t) = Ah(t) + Bu(t)$$

The exact solution over interval $[t, t+\Delta]$ via variation of parameters:

$$h(t+\Delta) = e^{\Delta A}h(t) + \int_0^\Delta e^{(\Delta-\tau)A} B\, u(t+\tau)\, d\tau$$

Under the Zero-Order Hold (ZOH) assumption — input $u$ is constant over each interval — the integral evaluates to:

$$\bar{B} = \left(\int_0^\Delta e^{sA}\, ds\right) B = (\Delta A)^{-1}(e^{\Delta A} - I)\Delta B$$

Giving the discrete recurrence:

$$h_t = \bar{A}h_{t-1} + \bar{B}u_t, \qquad \bar{A} = e^{\Delta A}$$

For diagonal $A$ (our implementation), all matrix operations reduce to element-wise: $\bar{A}_{ii} = e^{\Delta a_i}$, requiring no matrix inversion.

CNN as a Special Case of SSM

A causal FIR filter (finite impulse response) with coefficients $g_0, g_1, \ldots, g_k$ can be written as an SSM with $A$ being a shift matrix:

$$A = \begin{pmatrix} 0 & 1 & 0 & \cdots \\ 0 & 0 & 1 & \cdots \\ \vdots & & & \ddots \end{pmatrix}, \quad B = \mathbf{e}_1, \quad C = \begin{pmatrix} g_0 & g_1 & \cdots & g_k \end{pmatrix}$$

A convolutional layer with kernel $g$ is precisely an FIR filter applied at every position. Therefore: CNN = SSM with finite impulse response and time-invariant parameters.

Mamba relaxes two constraints: (1) the state matrix $A$ need not be a shift matrix (any stable diagonal $A$ is allowed), and (2) $B, C, \Delta$ can be input-dependent (selective). This gives SSM strictly more expressive power than convolution.

Attention as Kernel Regression

The softmax attention $\text{Attn}(Q,K,V)_i = \sum_j \frac{e^{q_i \cdot k_j / \sqrt{d}}}{\sum_l e^{q_i \cdot k_l / \sqrt{d}}} v_j$ can be viewed as a non-parametric kernel regression:

$$\hat{y}_i = \sum_j \kappa(q_i, k_j) \cdot v_j, \qquad \kappa(q, k) = \frac{e^{q \cdot k / \sqrt{d}}}{\sum_l e^{q \cdot k_l / \sqrt{d}}}$$

The kernel $\kappa$ is the exponential kernel (related to the RBF kernel) normalised over all key positions. This is the Nadaraya-Watson kernel estimator. Unlike convolution, the kernel weights $\kappa(q_i, k_j)$ depend on the content of the input — making attention a data-adaptive, non-linear, non-stationary filter.

SSM Transfer Function in the Frequency Domain

Taking the Laplace transform of the continuous SSM:

$$H(s) = C(sI - A)^{-1}B + D$$

On the imaginary axis ($s = j\omega$), this gives the frequency response:

$$H(j\omega) = C(j\omega I - A)^{-1}B + D$$

For diagonal $A$ with eigenvalues $a_i$ (all real, negative), the $i$-th pole is at $s = a_i$, contributing a first-order low-pass filter with cutoff $|a_i|$:

$$H_i(j\omega) = \frac{B_i C_i}{j\omega - a_i}$$

The full transfer function is a sum of these first-order filters — an infinite impulse response (IIR) filter with poles at $\{a_i\}$. This explains Mamba's smooth low-pass rolloff in frequency response experiments.

HiPPO Matrix & Memory Preservation

The HiPPO (High-order Polynomial Projection Operator) matrix $A$ is defined such that the SSM hidden state $h(t)$ encodes the optimal polynomial approximation of $u(s)$ for $s \le t$ in the $L^2$ sense with a measure $\mu$.

For the LegS (Legendre-Scaled) measure, the HiPPO matrix is:

$$(A_\text{HiPPO})_{nk} = -\begin{cases}(2n+1)^{1/2}(2k+1)^{1/2} & \text{if } n > k \\ n+1 & \text{if } n = k \\ 0 & \text{if } n < k\end{cases}$$

Our simplified diagonal initialisation ($a_i = -e^{\log(i+1)}$) approximates this: eigenvalues spaced log-uniformly give diverse memory timescales, from fast-decay (large $|a_i|$, recent history) to slow-decay (small $|a_i|$, long-term memory).
