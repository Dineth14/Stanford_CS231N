Complexity Scaling

CNN: Linear in Image Size

$$\text{FLOPs}_\text{CNN} = \sum_{l=1}^{L} 2 \cdot C_{l-1} \cdot C_l \cdot k^2 \cdot H \cdot W = \mathcal{O}(HW)$$

ViT: Quadratic in Patch Count

$$\text{FLOPs}_\text{ViT} = \mathcal{O}\!\left(\frac{H^2 W^2}{p^4} \cdot d\right) = \mathcal{O}(N^2 d)$$

For $H=W=512$, $p=16$: $N=1024$, attention matrix = $1024^2 \approx 1\text{M}$ entries per head. This is the primary bottleneck for high-resolution remote sensing.

Mamba: Linear in Sequence Length

$$\text{FLOPs}_\text{Mamba} = \mathcal{O}(N \cdot d \cdot N_\text{state}) = \mathcal{O}(N)$$

Mamba's linear complexity is its key advantage over ViT for long sequences. For hyperspectral images (hundreds of bands as a sequence), this is decisive.

Edge Deployment Note
Remote sensing edge devices (CubeSats, UAVs) have strict power and memory budgets. CNN's computational efficiency (no attention, hardware-accelerated convolutions) makes it the preferred choice for real-time on-board inference. Mamba is a promising alternative for sequential data (hyperspectral, time series).
