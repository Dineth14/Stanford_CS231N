Section 02

Architecture Deep Dive

Mathematical definitions, inductive biases, and design decisions for CNN, ViT, and Mamba.

CNN — Convolutional Neural Network

Definition

A 2-D convolution computes a sliding dot product between a learnable filter $g$ and the input feature map $f$:

2D Discrete Convolution
$$(f * g)[m, n] = \sum_{k_1}\sum_{k_2} f[k_1, k_2]\, g[m - k_1,\, n - k_2]$$

Inductive Biases

  • Locality: each neuron sees only a small neighbourhood (kernel size k)
  • Translation equivariance: shifting the input shifts the output by the same amount
  • Weight sharing: the same filter is applied at every spatial position

Weight Sharing — Parameter Count

For a single conv layer with $C_{in}$ input channels, $C_{out}$ output channels, kernel $k$:

$$P_l = C_{in} \cdot C_{out} \cdot k^2 + C_{out} \quad \text{(bias)}$$

Total for our 4-layer CNN:

$$P = \sum_{l=1}^{4} C_{l-1} \cdot C_l \cdot 9 = 3\!\cdot\!32\!\cdot\!9 + 32\!\cdot\!64\!\cdot\!9 + 64\!\cdot\!128\!\cdot\!9 + 128\!\cdot\!256\!\cdot\!9 \approx 385\text{K}$$

Convolution = Frequency Filtering

By the convolution theorem, convolution in the spatial domain is element-wise multiplication in the frequency domain:

$$\mathcal{F}[f * g] = \mathcal{F}[f] \cdot \mathcal{F}[g]$$

Each convolutional filter acts as a bandpass filter. Learned filters in early layers typically capture low-frequency structure (edges, blobs); deeper layers capture higher-frequency texture details. This is not a design choice — it emerges naturally from gradient descent on natural image statistics.

Our Implementation: SmallCNN

class SmallCNN(nn.Module):
    # 4 conv layers, no downsampling (stride=1, padding=1)
    # Channels: 3 → 32 → 64 → 128 → 256
    # Each layer: Conv2d → BatchNorm → ReLU
    # Spatial dims: 64×64 throughout (for full RF measurement)
    # Output: GlobalAvgPool → Linear(256, 10)

ViT — Vision Transformer

Patch Tokenisation

An image of size $H \times W$ is divided into non-overlapping patches of size $p \times p$. Each patch is linearly projected to an embedding of dimension $d$:

$$N = \frac{H}{p} \cdot \frac{W}{p}, \quad \mathbf{z}_0 = [\mathbf{x}_\text{cls}; \mathbf{E}\mathbf{x}_1; \ldots; \mathbf{E}\mathbf{x}_N] + \mathbf{E}_\text{pos}$$

For our model: $p=8$, $H=W=64$ → $N=64$ patches, $d=128$.

Self-Attention

Multi-Head Self-Attention
$$\text{Attn}(Q, K, V) = \text{softmax}\!\left(\frac{QK^\top}{\sqrt{d_k}}\right)V$$

Crucially, attention computes all-pairs interactions. Token $i$ can directly attend to token $j$ regardless of their spatial distance. This gives global receptive field from layer 1 — the opposite of CNN's local inductive bias.

Why ViT Has No Spatial Prior

Attention is permutation-equivariant: shuffle the tokens and the output shuffles the same way (because the softmax depends only on dot-products). The model must learn spatial structure from positional embeddings and data. Without them: the model treats the image as a bag of patches.

Quadratic Complexity

$$\mathcal{O}(N^2 d) \quad \text{per attention layer}$$

For a 512×512 image with patch size 16: $N = 1024$ tokens. Attention matrix = $1024^2 = 1\text{M}$ entries per head per layer. This makes ViT prohibitively expensive for large remote sensing images without windowing or linear approximation.

Positional Encoding

Our model uses learnable 1-D positional embeddings. Alternatives include: sinusoidal, 2-D factored, RoPE (Rotary Position Embedding), and ALiBi. All break under image-size changes at inference — a critical limitation for remote sensing where tile sizes vary.

Mamba — State Space Model

Continuous-Time SSM

A linear time-invariant system is described by:

Continuous-Time SSM
$$\dot{h}(t) = Ah(t) + Bu(t), \qquad y(t) = Ch(t) + Du(t)$$

where $h(t) \in \mathbb{R}^N$ is the hidden state, $u(t)$ is the input, $y(t)$ is the output.

Discretisation — Zero-Order Hold

For a discrete sequence with time step $\Delta$:

$$\bar{A} = e^{\Delta A}, \qquad \bar{B} = (\Delta A)^{-1}(e^{\Delta A} - I)\Delta B$$ $$h_t = \bar{A} h_{t-1} + \bar{B} u_t, \qquad y_t = Ch_t + Du_t$$

For a diagonal $A$ (as in our implementation), the matrix exponential is element-wise: $(\bar{A})_{ii} = e^{\Delta a_i}$, which is computationally efficient.

HiPPO Matrix Initialisation

Gu et al. (2020) showed that initialising $A$ as the HiPPO matrix — derived from Legendre polynomial optimal projection — allows the SSM to faithfully memorise the entire input history. Our simplified implementation uses log-spaced eigenvalues (a diagonal approximation):

$$A_{ii} = -e^{\log(i+1)}, \quad i = 0,\ldots,N-1$$

The negative real eigenvalues ensure stability ($\bar{A}_{ii} \in (0,1)$). Larger eigenvalues (near 0) decay fast → encode recent history. Smaller eigenvalues (near 1) decay slowly → encode distant history.

Selective Scan (Mamba's Key Innovation)

In S4, $A, B, C$ are input-independent (time-invariant). Mamba makes $B$, $C$, and $\Delta$ input-dependent:

$$B_t = \text{Linear}(x_t), \quad C_t = \text{Linear}(x_t), \quad \Delta_t = \text{softplus}(\text{Linear}(x_t))$$

This allows the model to selectively remember or forget based on content — analogous to gating in LSTMs, but more principled.

Linear Complexity

$$\mathcal{O}(N \cdot d \cdot N_\text{state})$$

Unlike ViT's $\mathcal{O}(N^2)$, SSM complexity grows linearly with sequence length. For hyperspectral images (hundreds of bands as a sequence) or large image tiles, this is a critical advantage.

2D Images → 1D Sequences

Mamba is inherently 1-D causal. For images, common strategies are:

  • Row-major: flatten H×W → L tokens (simple, loses 2D structure)
  • Hilbert curve: space-filling curve preserving locality better
  • Bidirectional: process left→right and right→left, concatenate
  • VMamba: 4-directional scan (VSS block)

Our implementation uses 4×4 patch embedding → 16×16 = 256 token sequence (row-major).
