Decision Flowchart: Which Architecture to Use?

Flowchart Logic
  1. Is the dataset small (<50K images)? → Prefer CNN (strong inductive bias) or Mamba (less hungry than ViT).
  2. Do objects require global context (flooding, land use)? → If yes: ViT (unlimited RF) or Mamba (long causal memory). If no (roads, buildings): CNN.
  3. Is the input a 1D spectral sequence (hyperspectral)? → Mamba first, ViT second, CNN last.
  4. Is inference memory constrained (edge devices)? → CNN first (O(N) memory), Mamba second, avoid ViT (O(N²)).
  5. Is interpretability required? → CNN (filter visualisation), ViT (attention maps), Mamba (complex).

Pros & Cons Cards

CNN Pros
  • Parameter efficient
  • Translation equivariant (inductive bias)
  • Fast inference, O(N) memory
  • Works well on small datasets
  • Stable training, easy to tune
  • Interpretable filters (Gabor-like)
ViT Pros
  • Global RF from layer 1
  • Scales well with more data
  • Attention maps provide attribution
  • Flexible positional encoding
  • Strong with pretraining (DINO, MAE)
  • Data-adaptive frequency filtering
Mamba Pros
  • O(N) complexity with global context
  • IIR filters: richer frequency response
  • Natural fit for sequential/spectral data
  • Selective: ignores irrelevant tokens
  • Long-range memory via stable eigenvalues
CNN Cons
  • RF grows only linearly with depth
  • Cannot model long-range dependencies
  • Aliasing with strided convolutions
  • Cross-sensor transfer is fragile
ViT Cons
  • O(N²) attention: huge memory cost
  • Data-hungry without pretraining
  • Learnable pos. embed. breaks for new sizes
  • Quadratic cost prevents large images
Mamba Cons
  • Causal scan breaks 2D symmetry
  • Vertical pixel relationships degraded
  • Harder to interpret than CNN/ViT
  • Less well-studied for vision tasks
