Section 09

Failure Modes

Known failure cases for each architecture, with mathematical explanations and remote sensing implications.

CNN Failures

1. Limited Receptive Field → Missing Global Context

Proven: for $L$ layers with kernel $k$ and stride $s=1$, the theoretical RF is at most $1 + L(k-1)$. For $L=4$, $k=3$: $\text{RF}=9$ px. Objects larger than 9 px cannot be recognised by a single neuron — only ensemble effects across spatial positions help.

$$\text{RF}_L = 1 + \sum_{i=1}^{L}(k_i-1)\prod_{j<i}s_j \le 1 + L(k-1)$$

2. Not Globally Permutation-Equivariant

CNNs are locally translation-equivariant but not globally permutation-equivariant. Cropping or padding an image changes the absolute position of objects relative to the image border — which affects feature map positions and final classification.

3. Fixed Filter Banks → Cross-Sensor Failure

CNN filters encode a fixed frequency decomposition. When transferring from optical to SAR (very different spectral statistics), the learned filters may be entirely mismatched. This is why optical-pretrained CNNs fail dramatically on SAR without fine-tuning.

4. Aliasing from Strided Convolutions

Strided convolutions without anti-aliasing violate the Nyquist sampling theorem. For a convolution output at stride $s$, frequencies above $f_s / (2s)$ are aliased. Zhang (2019) showed this causes inconsistent classifications under small image shifts.

ViT Failures

1. Data Hunger

Without strong inductive biases, ViT must learn spatial structure from scratch. Dosovitskiy et al. (2021) showed that ViT-L trained on ImageNet-1K (1.3M images) alone underperforms ResNet — only with JFT-300M (300M images) does ViT win. Remote sensing datasets rarely have >100K labelled examples.

2. Quadratic Attention Complexity

For a 512×512 image with patch size 16: $N=1024$ tokens. Attention memory per layer: $N^2 = 1\text{M}$ entries. With 4 heads × 4 layers: $16\text{M}$ attention values. For patch size 8: $N=4096$, attention = $16\text{M}$ per head.

$$\text{Memory}_\text{attn} = \mathcal{O}\!\left(\frac{H^2W^2}{p^4}\right)$$

3. Uniform Attention at Initialisation

At random initialisation, $Q$ and $K$ are random. The softmax of random dot-products tends to uniform distribution ($1/N$ per token). Formally:

$$\lim_{\sigma \to 0} \text{softmax}(QK^\top/\sqrt{d}) = \frac{1}{N}\mathbf{1}\mathbf{1}^\top$$

This means ViT starts as a simple mean pooling — no spatial structure. The model must learn attention patterns entirely from gradients, explaining slow convergence.

4. Positional Encoding Breaks Under Size Changes

Learnable positional embeddings are defined for a fixed sequence length $N$. At inference with a different image size, the embeddings must be interpolated (bicubic) — introducing errors proportional to the size difference. Remote sensing inference on tiles of varying sizes requires careful handling.

Mamba Failures

1. Causal Design — 2D Spatial Reasoning Difficulty

Mamba was designed for causal 1-D sequences (text, audio). In row-major 2D unrolling, the token at position $(i, j)$ can only attend to tokens $(0,0), \ldots, (i,j-1)$ from previous rows and columns. Pixels in the same column $j$ but different rows are separated by $W$ tokens — breaking vertical spatial locality.

2. Row-Major Scan Loses Vertical Relationships

For an image of width $W=64$: pixel $(y, x)$ and $(y+1, x)$ are 64 tokens apart in the sequence. For $W=512$: 512 tokens apart. The SSM's ability to remember vertical neighbours degrades linearly with image width.

3. No Global Attention

Unlike ViT, Mamba cannot directly compare non-adjacent tokens in the scan order. Token $(0,0)$ and token $(N-1, N-1)$ interact only through the hidden state path of length $N$ — with exponential decay controlled by $\bar{A}$.

4. Numerical Instability Near Unit Circle

If any eigenvalue of $\bar{A}$ approaches 1 (i.e., $\Delta a_i \approx 0$), the hidden state grows unboundedly — analogous to a marginally stable system. The $\text{softplus}$ activation on $\Delta$ prevents exact zero but doesn't preclude near-instability with poor initialisation.
